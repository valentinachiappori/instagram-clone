# Variables de entorno

Antes de ejecutar el proyecto, es necesario crear un archivo `.env` en la raíz de `Api/` con las siguientes variables:

```env
JWT_SECRET=
PORT=
```

Por ejemplo:

```env
JWT_SECRET=clave_secreta
PORT=3000
```

**Importante:** Este archivo no se encuentra versionado en el repositorio, por lo que cada desarrollador debe crear su propio `.env`.
